Do not run the launcher from inside a ZIP preview. Extract the archive into a normal folder first.

03

On 64-bit Windows 10/11, double-click START_DEMO_WINDOWS.bat. The bundled runtime avoids a separate Python installation. Mock mode spends no API credit.
