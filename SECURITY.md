# Security

Do not open a public issue containing credentials, payment information,
customer data, or a reproducible exploit against a live deployment.

For this Lite repository, first confirm that a report applies to the files in
this repository rather than the separate commercial kit. Remove all secrets and
personal data before sharing a reproduction.

The calculator is a static browser application and should not require API keys.
If any copy asks you to enter a provider key into the calculator, stop and verify
that you are using the repository linked from the official product page.
